Task and object identities
--------------------------
112a70 scans256 task records of52 bytes. Tag0 does nothing. A tag>65535
matches the complete word, otherwise only the low16 bits. Matching tasks
save the old tag at+30,set state+4=4,clear tag+14 and release stack+18.
1124b8 clears only an8-byte stack header when flag4 is set, increments its
counter and prints a diagnostic. Duplicate references must not count twice;
the task drops its reference even if the header was already cleared.

11e3a0 scans256 objects of320 bytes. Its full-word selection uses SIGNED
comparison, unlike task cancellation: high-bit tags do not match low16 IDs.
Each match zeros the record, links+138 to the old free head and prepends this
slot. Ascending scan therefore produces descending free-list order. Counters
wrap at32 bits. Tests include zero/short/full/high-bit tags, shared stacks,
both players, matching/nonmatching tasks and counter overflow. EE word
arguments in the oracle are sign-extended as produced by SLL/ADDU/LW;
zero-extending high-bit test arguments creates a false LW comparison failure.
