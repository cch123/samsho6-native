Mina Majikina (resource / character 24) - character-specific code specification
================================================================================

Scope: static reverse engineering of the pinned ELF work/ss6/extracted/SLPS_255.59
(MIPS R5900 LE). Every statement was read from the disassembly (analyze_elf.py)
with delay slots accounted for, unless marked INFERRED (meaning assigned from
usage) or UNVERIFIED (not confirmed). No Probe comparison has been run for any
function below; nothing here is runtime-verified. The common move-script
interpreter (163590/163610 and helpers) is specified in docs/script-engine.txt and
is only referenced here by script id / row.

Conventions (shared with docs/script-engine.txt)
  cb      callback argument: cb[0] = own actor, cb[1] = opponent actor
          (169798 fills cb[1] = 1400a8(actor.a24)), cb[2] = actor.callbacks260[2].
  actor   StateEntryActor. +0x000 body (PlayerObject), +0x004 aux = Chample object
          handle (StateEntryActor::auxiliaryObject04), +0x194 state194 (low half =
          table, high half = index), +0x23c flags23c, +0x244 flags244, +0x248
          flags248, +0x260..+0x278 callbacks260[0..6], +0x2c4 sampledFeatures,
          +0xa10 character, +0xa24 player slot, +0xa30 life (fieldA30),
          +0xa3c queuedActionA3c.
  object  pool object words: +0x24 ACT, +0x28 record index, +0x30 clock delta,
          +0x38 objectFlags (0x80000 = mirrored / facing screen-left, 0x1000),
          +0x40 x, +0x44 y (float), +0x4c/50/54 x offset/velocity/accel and
          +0x58/5c/60 y (16.16 ints), +0xc0 "ACT finished" word, +0x104 flags104,
          +0x108 flags108, +0x110/+0x114 ACT attachment offsets (ints),
          +0x118 owner actor, +0x128..+0x134 per-object scratch, +0xd0 projectile
          descriptor id, +0xd4 special index-64, +0xf4 float scratch.
  ended   (o.c0 != 0 && !(o.104 & 1)), the idiom used by every handler below.
  bind(h) 1522a0(actor+0x260, h, 0, -1): callbacks260 = {h, 0, -1}, words 3..6
          untouched.  NOTE: Mina's code always passes table word 0 (Hanzo/Rimururu
          ports bind with 1); preserve the 0.
  queue(n) 1493c0(actor, n, 0) (non-forced ACT request; also applies the 168c18
          lock table, see section 11).
  stop(o) 11d990 (zero motion words).  req(o,n,i,f) 11d908(o, n, immediate i,

          0x80000 of src.38 into o.38.
  RNG(n)  112300(n) = GameRandom bounded draw (library generator).

Evidence key: [P] already ported in src (cite), [N] not ported.

  void mina_attack(cb) {
      sel      = cb[2];
      script   = 163570(sel);        // sel>=0x80 && sel!=0xff ? sel-0x80 : -1

        case 0:  tailcall 1fba08(cb, 0);   case 1: 1fba88(cb, 0);
        case 2:  1fbb08(cb, 0);            case 3: 1fbc40(cb, 0);
