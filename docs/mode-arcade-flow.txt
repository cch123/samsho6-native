ARCADE MODE scene flow outside the fight (SLPS-25559, static analysis)
=====================================================================

Scope: everything between "ARCADE confirmed in the mode menu" and "hand-off to
the ending scenes", excluding in-battle round logic. Source: static reading of
work/ss6/extracted/SLPS_255.59 with analyze_elf.py. No Probe run was used; every
statement below is static. Labels:
  OBSERVED = read from instructions/data at the cited address.
  INFERRED = interpretation of observed code.
  UNKNOWN  = not read / not resolved.
All addresses hexadecimal. "P[s]" = player setup record 0x456890 + 0x30*s.
"G" = g_GameData 0x4c3808. "S" = arcade schedule record 0x12d3668.
"O" = option block 0x43d058. random(n) = 0x112300(n) (GameRandom bounded).
Scene switch = 0x1252f0(kind, speed, destructor, nextEntry).

Glossary: CPU (computer-controlled seat), RNG (random number generator),
BGM (background music), HUD (heads-up display).
