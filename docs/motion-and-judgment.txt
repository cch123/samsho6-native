动作时间与运动的调用顺序
0x120ce0：先 0x120618 更新运动，再 0x120880 绘制提交，再 0x120ac8 推进动作。
查看器展示推进后的可检查状态；尚未验证整条 PS2 主循环的显示/输入采样相位。
0x120390 设 action、清 step/time/end、设置 object+0x38 的 0x10000000，并调用 0x120d10。
0x120d10 每次阶段进入清 object+0x3c；若 object+0xc0 已完成且 +0x104 bit0 未设，跳过运动命令。
0x120c58 循环时保留 endReached=1，并清 0x10000000。非循环末尾保留阶段，写结束码。
0x1697d0 -> 0x11d990 是停止运动的已找到路径，清六个运动字段；
完整输入状态切换还没移植，不能用“进入动作 0”代替停止，因为动作 0 的命令不会清速度。

运动字段与数值语义
object +0x4c,50,54,58,5c,60：dx,vx,ax,dy,vy,ay，均 32-bit signed word。
dx/dy 为 16.16 偏移。+0x40/+0x44 是 float 坐标；+0xc8==1 时将偏移 /65536 加入坐标再清偏移。
ACT +0x22/24：瞬时偏移，乘 65536。
ACT +0x26/28：速度，乘 256。
ACT +0x2a/2c：加速度，乘 16。
actor +0x108 的 0x200 控制命令内 X 速度/加速度符号；
object +0x38 的 0x80000/0x40000 控制坐标提交 X/Y 镜像，是另一组独立状态。
0x120660..0x1206a8 每次先加位移再加速度，乘积取低 32 位后算术右移 8。
不允许用无限精度乘积或有符号溢出的 C++ 表达式代替。
10/11 原始 vx=544*256，即普通增量下每次 +2.125 坐标单位。
12/13 原始 vx=-480*256，即普通增量下每次 -1.875 坐标单位。

0x5df3d8 的 19 项跳转表已直接读取：
0：保留六个字段。
1..4：清六个字段。
5..8：设置 dx/dy 并清速度/加速度；+0x104 bit0x80 可阻止偏移赋值。
9：设 vx/vy，清 ax/ay。
10：设 vx/vy/ax，清 ay，vx 加 ax 算术右移 1。
11：设 vx/vy/ay，清 ax，vy 加 ay 算术右移 1。
12：设两轴速度/加速度，并各加半个加速度。
13/14/15：只更新 ax / ay / ax 与 ay。
16..18：该算术分支不变。
2/4/6/8/16/18 另设置对象 +0xfe bit0x80；算术 helper 本身不含这个状态副作用。
特殊跳跃倍率、冻结、绑定对象等分支仍未实现；不宣称 19 种完整行为均已还原。

JDG
0x152fd8 读取 ACT+0x1e，取低三位得到数量；指针为 ACT+0x0e 的 signed16 数组。
0x11db40 使用 JDG_pointer[slot]+index*16。JDG 从零计数，0 是合法记录，不是空值。
每条 16 字节：+0 uint32 metadata；+4 signed16 auxiliary；
+6/+8/+0a/+0c 是 signed16 的 x1/y1/x2/y2；+0e signed16 tail，辅助字段完整含义待查。
0x153028 解 metadata：type = word>>26；
中间 7 bits=(word>>19)&127，除 6 再拆分；bit18、bits7..17、bits0..6 另保留。
目前保持原始字段，未擅自命名为伤害、优先级或停顿时间。
0x153170 先整理局部矩形的最小/最大端点，再按对象方向和世界坐标变换。
先把第一个端点向零截成整数，再从该整数推导另一个端点；跨零小数坐标不能各自截断。
0x1532d0 相交判定包括边界；共边/共角均成功，宽度=right-left+1，中心和除以 2 向零截断。
失败只清 out.touches，保留其余输出字段。代码和测试保留这个行为。
查看器以颜色标记 raw type，文字 t0/t1/t2/t3/t10 不等于完整攻防属性解码。
