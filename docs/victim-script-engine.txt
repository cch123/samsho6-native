Common victim-side "table B" script engine (165780 .. 168960)
==============================================================

Scope: static reverse engineering of the pinned ELF work/ss6/extracted/SLPS_255.59
(MIPS R5900 LE) with analyze_elf.py, delay slots accounted for. Nothing below has
been compared against a Probe trace; nothing is runtime-verified. Tags:
  [R] read directly from the disassembly / data;
  INFERRED  meaning assigned from usage or from other docs;
  UNVERIFIED  not confirmed.
The table-A (attacker move-script) engine is docs/script-engine.txt. Character-24
callers are docs/mina-callbacks.txt section 5. Existing hand ports:
src/nakoruru_capture.cpp (updateFighterCapture), src/hanzo_capture.cpp.

Conventions
  cb        callback argument {cb[0], cb[1], cb[2]}. In this engine cb[0] = VICTIM
            actor ("V"), cb[1] = ATTACKER actor ("A"), cb[2] = V.callbacks260[2]
            (= k, the damage-state index - 80, written by the 14cc10 registration).
  sp-cb     169780(sp) + 169798(sp, actor): a temporary callback argument built on
            the stack with sp[0] = actor, sp[1] = 1400a8(actor.a24) (its opponent).
  reg       V+0x28c (registry28c, 13 words). Table-B engine use:
              r[0]  current row index (relative to r[12])
              r[1]  index of the row whose entry has been applied (-1 initially)
              r[2]  set to -1 by 1634e8, not otherwise used here
              r[3]  strength (1696c8 of the attacker, 0..2)
              r[4], r[5]  latched offset (s16 << 16) for 166ce8 (from 166db0)
              r[7], r[8], r[9]  "wait done" flags for victim / attacker / object
              r[10] adopted object (row flag 0x40), else 0
              r[12] row base address in table B
  child     V.body+0x124: the object that delivered the contact (projectile,
            companion...), 0 for body contacts (INFERRED from native_match.cpp:214
            which stores the source handle only for object contacts).
  eff_tab(a)/eff_idx(a)   1500a8 / 1500d0: (a.23c & 0x200000) ? a.1a4 : a.194
            halfwords (effective state aliases) [R].
  ended(a)  149488(a): actor's body ACT finished (INFERRED from existing ports).
  ended(o)  o.c0 != 0 && !(o.104 & 1) (object form, [R] in 1663b8).
  queue(a,n)       1493c0(a, n, 0).
  queue2(a,x,y)    1494c0(a, x, y, 0) = queue(a, (a.23c & 0x1000) ? x : y) [R]
                   (0x1000 = armed; x = armed ACT, y = unarmed ACT).
  bind(a,h,t)      1522a0(a+0x260, h, t, -1): a.260 = h, a.264 = t, a.268 = -1.
  req(a,t,i)       14ff80(a+0x18c, t, i): a.190 (s16) = t, a.192 (s16) = i [R];
                   it does NOT write a.18c. 150090(a+0x18c) = {18c=0, t=-1, i=-1}.
  timer clear      14d000(a+0x1ac, n): a timer n = 0.
  timer inc        14d038(a+0x1ac, n): old = t[n]; t[n] = min(old + delta, 0x173400)
                   (signed compare); returns OLD [R] (= native ActorTimers::increase).
  stop(o)          11d990 (motion words cleared; docs/projectile-engine.txt).
  print(...)       316140 debug printf (no state effect).

0. Flow overview
--------------------------------------------------------------------------------

  contact (raw JDG type 36..63, or route-4 capture index)          [section 9]
     |   V.254 = attacker character, V.body.124 = source object or 0,
     |   V requests (2, 80+k)
     v
  V enters damage state 80+k; 14cc10 registers V.260 = {table4e97a8[V.254], 2, k}
     |
     v  (next callback visit of V)
  damage-source dispatcher (Mina: 1fb970)
     row = 165780(char, k)  -> k or -1
     str = 1696c8(A)
     V.260[0] = 0
     1657b0(cb) == 0 ? ----------------------------- yes --> return (fail path ran
     |                                                         1688c8; see 2)
     no
     row == -1 ? --- yes --> 169810(cb) (ordinary recovery)
     |
     no
     165a78(cb, char, row, str)  [section 4]
        |
        +-- 168318 refuses (invalid source / KO of paired attacker) -> return
        |
        +-- 165f18 enters row 0
        |      |
        |      +-- row is last AND has no waits (166330) -> 166390: end ops,
        |      |                                             script finished
        |      +-- otherwise bind(V, 0x165cc0, 2)
        v
  165cc0 each visit  [section 5]
     165da8 per-visit positioning / constraint
     1663b8 waits complete? -- no --> return
        | yes
     1667f8 end ops of current row
     row last? -- yes --> 168560 (print only), finished
        | no
     r[0]++; 165f18 enter next row; 166330? -> 166390 (end ops + finish)

1. Row lookup
--------------------------------------------------------------------------------
165780(char, id) -> int  [R]
    return 1633c0(char, id) != 0 ? id : -1;
  NOTE: it returns the id, not the row pointer. 165a78 / 1688c8 look the row up
  again through 1634e8.
1633c0(char, id): table B pointer 0x4e4a68[char]; first 20-byte row with
  byte0 == id, the search ends at the first row with byte0 == 0xff (checked
  after the id compare). Rows following the first match are reached only by
  r[0]++ in 165cc0, whatever their byte0 (Mina rows 0x4e3aa8/0x4e3abc both have
  id 3; Hanzo rows repeat their id).
1634e8(reg, char, id, str): reg[12] = row; if row { reg[3] = str; reg[2] = -1;
  reg[0] = 0; reg[1] = -1; reg[7] = reg[8] = reg[9] = 0 }.

2. Row layout (20 bytes)  -- every reader listed
--------------------------------------------------------------------------------
  +0x00 u8   id (lookup key only).
  +0x01 u8   not read by this engine (0 in all observed rows).
  +0x02 s16  victim ACT offset. -1 = none. Queued as 0x500 + value:
               type (+0x13) == 6 or 0x58: queue(V, 0x500+v)
               otherwise:                 queue2(V, 0x500+v, 0x501+v)   [165f18]
  +0x04 s16  attacker ACT (raw id in the attacker's bank), -1 = none.  [165f18]
               type 0x4a: kept only if eff_tab(A) == 1 && eff_idx(A)-80 < 4
                          (unsigned), else -1 (plus a debug print)
               type 0x29: += A.byte[0xf16]
               type 0x41: += (2 - A.byte[0xf1b]) * 2
               flag 0x02: (type 1: += 2*r[3]); queue2(A, act, act+1)
               else:      (type 1: += r[3]);   queue(A, act)
  +0x06 s16  object ACT for the child (V.body.124), -1 = none:
               11d908(child, act, 0, 0)   (NO null check on child)
               if child.14 == 4 && act == 0x328: 11db88(child) (toggle mirror
               bit 0x80000).                                         [165f18]
  +0x08 u8   wait type for the victim   (slot 0)  \
  +0x09 u8   wait type for the attacker (slot 1)   > 0 = no wait. [1663b8, 166330]
  +0x0a u8   wait type for the child    (slot 2)  /
  +0x0b u8   end op for the victim   (slot 0)  \
  +0x0c u8   end op for the attacker (slot 1)   > 0 = none.        [1667f8]
  +0x0d u8   end op for the child    (slot 2)  /
  +0x0e s16  parameter "e": requested damage/normal index for end ops 1..3,
             tick count (<<8) for wait type 6, and the third argument of the
             type handler 166e98.
  +0x10 s16  script damage. Non-zero: 1413d8(V.a24, value, child ? child :
             A.body, 1) at row entry (1413d8 -> 1a41b8 scaling -> 14a8d0 life
             change; internals UNVERIFIED). Hanzo rows 16/22/35/9/12/20/45.
  +0x12 u8   flags:
             0x01 last row. 166330: last && bytes 8..10 all zero -> script
                  finishes on entry. 165cc0: last -> finish after end ops.
             0x02 attacker ACT is an armed/unarmed pair (queue2).
             0x04 after each queued ACT set the owner body's FE |= 8 (victim body,
                  attacker body, child respectively).
             0x08 on entry 166c28(reg, V, A.body)  (split anchor, section 6).
             0x10 if 0x08 clear: 166c28(reg, V, child).
             0x18 (read as lhu & 0x18, i.e. still byte-0x12 bits 3/4): if type
                  is 3, 5 or 0x1c, latch 166db0(reg, V, V.a3c, 0) after queueing
                  the victim ACT (record 0 of the queued ACT).
             0x20 "paired": attacker control is taken (165a78) and 168318 also
                  refuses when the attacker is damaged / dead.  Tested on ROW 0
                  only.
             0x40 adopt the child (165a78, ROW 0 only).
             0x80 168750 weapon operation at row entry (165f18); 1688c8 also
                  runs it on the fail path, ROW 0 only.
  +0x13 u8   row type: per-visit positioning in 165da8, ACT selection details
             in 165f18, end-op 9 values, and the 166e98 entry handler.
             0xff (and any value >= 0x5d) = no type behaviour.
