# 素材替换

游戏从一个基础素材目录读取文件，并允许用覆盖目录中的同名文件替换其中任意一个。基础目录保持不动，删除覆盖目录即恢复原状。

## 覆盖目录

```sh
./select.command --mod mods/my-mod                       # 可重复，靠前的优先
SS6_MODS=mods/a:mods/b ./select.command                  # 等价的环境变量形式
```

查找规则：

```
加载器请求 assets/<文件名>
        │
        ▼
依次检查每个覆盖目录下是否存在 <文件名> ──是──▶ 使用该文件
        │否
        ▼
使用 assets/<文件名>
```

- 只按文件名匹配，覆盖目录是平铺的，与基础目录同构。
- `--mod` 指向不存在的目录会直接报错，避免静默读取原版数据。
- 玩家存档（`--save`）不参与覆盖。
- 探针和回放工具同样遵守 `SS6_MODS`；做原版对比验证时不要设置它。

## 贴图

`.tex` 是无文件头的 8 位索引图，可选在末尾附带 256 项 32 位调色板；独立的 `.pal` 是 256 项 16 位（512 字节）或 32 位（1024 字节）调色板。尺寸和调色板顺序不在文件里，`ss6tex.py` 解码时把它们写进 PNG 旁边的 JSON，编码时读回。

```sh
A=outputs/ss6-feasibility/native-viewer/assets
python3 tools/assets/ss6tex.py decode $A/bg_title00.tex -o art/bg_title00.png
# 用支持索引色的编辑器修改 art/bg_title00.png
python3 tools/assets/ss6tex.py encode art/bg_title00.png -o mods/my-mod
./title.command --mod mods/my-mod
```

`python3 tools/assets/ss6tex.py verify $A --scratch <空目录>` 会把目录内每张贴图解码再编码并逐字节比较，用来确认工具对当前数据集无损。

编辑时的约束：

- PNG 必须保持索引色模式。游戏按编号引用调色板项，若干画面还会在运行时换调色板，真彩色图无法导入。
- 不要改变图片尺寸。加载器按原版尺寸校验文件大小，尺寸不符会在启动时报错。
- 16 位调色板每通道只有 5 位，透明度只有 1 位；编码时会截断到该精度。
- 没有同名 `.pal` 且无内嵌调色板的贴图（如 `sakura.tex`）的调色板来自别处（由使用它的加载器决定），解码结果用灰阶预览，编码时只写回索引。
- 少数贴图页是每字节两个 4 位像素，或宽高不是工具推断的默认值；这类需要用 `--width` 指定，4 位页目前不支持。

## 目前可以替换什么

| 素材 | 文件 | 可编辑格式 | 状态 |
|---|---|---|---|
| 界面、背景、立绘、场景贴图 | `*.tex` / `*.pal` | 索引 PNG | 可用，往返无损 |
| 角色精灵 | `chr/pil/idx/map_NN.bin` | 无 | 只能整文件替换，尚无转换工具 |
| 动作与判定框 | `aid/act/jdg_NN.bin` | 无 | 同上，格式见 action-format.txt |
| 音乐、音效 | `*.vb`、`vs_sounds_NN.bin` | 无 | 同上 |
| 数值表 | 其余 `*.bin` | 无 | 同上，字段含义见对应专题文档 |

整文件替换始终可用：把同名文件放进覆盖目录即可，但文件必须满足加载器检查的大小和布局。
