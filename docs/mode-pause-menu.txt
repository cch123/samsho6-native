3  Task 1d9e10 [V]
------------------

One visit:
  1392e8();                                   // word 123a0c4 = 1, section 7
  seat = mode 1/0xb -> 0, mode 2/0xc -> 1, mode 3 -> 582f3c, else 0;
  if (582f50 != 0) return;                    // a child window is open: nothing else, no draw

          1 = repeat & 0x10 (up), 2 = repeat & 0x20 (down), 4 = pressed & 0x80 (right),
          8 = pressed & 0x40 (left).
  Priority chain (first match only):
   in & 0x40          1da110() (close); sound (-1, 0x25).
   in & 5  (up/right) state 0: cursor = (cursor + rows - 1) % rows; 1da860();
                      state 2 or 6: 582f40 ^= 1;   state 5: state = 0;   sound (-1, 0x20).
   in & 0xa (down/left) the same with cursor = (cursor + 1) % rows.
   in & 0x20 (cancel) state 0: 1da110();  state 2 or 6: state = 0, 582f40 = 1;
                      state 5: state = 0;   sound (-1, 0x25).
   in & 0x10 (confirm) 1da508(); 582f48 = 0; sound (-1, 0).
  Draw (section 8): if (state != 5) the menu; if (state == 6) dialog(choice, 0);
                    if (state == 2) dialog(choice, 1).
  if (582f48 < 10) 582f48++.

rows = 4 when sub-mode == 5, else 6. Left/right act as down/up in every state, including the
row list. Sounds are 1e7b70(-1, id): 0x20 move, 0 confirm, 0x25 cancel/close; the confirm
tone is requested even when the confirm closes the menu or requests a scene.
The visit that closes the menu still draws it (the task is released by tag, the running
visit completes).

State word 582f34: 0 row list, 1 CANCEL chosen (set just before the close), 2 character-select
question, 5 WINDOW OFF (nothing drawn), 6 title question. 582f40: 0 = yes, 1 = no.

10  Corrections to earlier documents
------------------------------------

docs/mode-battle-branches.txt section 12:
  - Mode 2 opens without the 181778() test; mode 1 has it only after the pad test.
  - Left/right are accepted as down/up everywhere, also in the row list.
  - CHARACTER SELECT / RETURN TO TITLE need two confirms: the first only enters the question
    (states 2 / 6), with "no" preselected.
  - The fourth row of sub-mode 5 is NEOGEO LAND with its own question and help line.
