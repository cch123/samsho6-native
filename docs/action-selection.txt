Original input-to-state selection (SLPS_255.59)
=============================================

Native implementation: src/action_selection.hpp/.cpp.
This layer selects logical states and writes pending requests. It does not
execute PS2 code, start animations or consume command buffers. The offline
Probe runs original functions for comparisons only. Current battle.command
still uses direct TrialCommand controls; this library is not live-integrated.

Original tables
---------------
extract_action_selection.py pins the ELF and copies these original bytes:
4d5ba0: normal transition64x31;4d6360: attack64x17;4d67a0: chain64x17.
4d6be0: alternate normal map64;4d6c20: alternate attack map64x2.

Exact sizes/hashes are in action_selection_tables.json. Transition255 means
refused; transition values are logical state indices, not animation IDs.
Character indices here describe helper data, not implemented playable actors.

Normal selection
----------------
1505d0 looks up a normal transition, then optionally remaps it for23c800000.
150410 prioritizes recognized slots24,25,26,27,28,30,29, with system-specific
substitutions after lookup. Slot30 precedes29. Refused candidates fall through.
14f5d8 maps system8->5; system6 descriptor byte4 selects its column.
1501e8 then checks slots19,13,12,0,1 before directions49..56(default8).
Raw packed194 equal normal62/46 overrides this sequence: flags8000/10000
and held features91/92 decide whether to stay or return0.
Turning can select column9. Opponent threat selects guard columns10/11 via
featuresd8/d4. A refused final direction preserves the incoming state.

150dd8 is a separate restricted normal selector. It uses raw transitions,
system substitutions, then1511e0's descriptor bit2; it does NOT use800000
remaps or normal62/46's early held-pair gate. A filtered candidate falls
through. It turns BEFORE inspecting bodyPendingFE100;1501e8 checks pendingFE
first. Even if no new state is queued, selection may have changed facing.

Attack and supplemental selection
---------------------------------
150620/150850 use attack/chain matrices. Flag23c800000 enables the alternate
mapping; armed1000 chooses its first column, unarmed its second.
Recognized5/6 choose column15 and setA48=0/1 only on accepted transitions.
Then14 (chain also16), then2/3. Raw edges6,7,8,9 follow fixed button priority.
Down and diagonal predicates select columns; character32 flags244400 blocks
button9. No edge returns-1; a refused edge returns255 and does NOT try the
next button. These values have distinct meanings at the selector boundary.

150aa8 returns packed table*256+state for slots20/21/22, respecting raw
state36 and permission bits.150b60 handles slots23,9/10,4,16/8,11/17/15/18
and damage0..5 recovery. Their raw table accesses bypass800000 remaps.
The last four normal candidates choose the FIRST recognized candidate, not
the first accepted table cell.150d60 rejects effective normal states25..30.

Guard and threat
----------------
151428 denies system8/system6 descriptor12==40, flags2442 or23c10.
151478 first rejects own airborne flag. Opponent attack table1 with cached
battle+144 distance<240 is threatening. This uses the stored signed integer,
not a newly calculated float distance. Any registered opponent object kind2
or5 also qualifies; original140d78 scans48 slots through1473b8.

1a3798 consults the opponent's SEPARATE actor+4 auxiliary object:
character1/45:state128 in6/7;4:14/18/24/25/26/31/38/41/45;
16:flag134!=0;19:state13;24:30;32:7/8;34:13/16/17. Other keys false.
Finally, attack-table opponents may qualify by168fc8's character/action pair
even at distance>=240. Body action and auxiliary state are not interchangeable.
SelectionThreat represents the original cached distance and present object
kinds. Their gameplay producers are still separate integration dependencies.
