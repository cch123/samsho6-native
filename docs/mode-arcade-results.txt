8. DIFFERENCES FROM ArcadeSession::follow() AND WIRING
------------------------------------------------------
follow() applies winQuoteExit / versusResultExit at once. The original differs in three ways:
  - the exit happens only on START (frame >= 10 resp. 1f, g+18 == 0) or when the end counter
    reaches 1e0 (resp. f0); the scenes request music 19 at entry;
  - destructor 136288 clears g+1c (versusInterrupted) unless g+0 == 3. follow() never clears it,
    so after one challenger fight every later arcade win quote would again lead to the VS result.
    The destructor runs at the transition midpoint, AFTER winQuoteExit has read g+1c;
  - kind-4 exits (intruder due) play the challenger banner (125c68) before the shutter.
Unlock: ArcadeSession::tickGameOver passes unlockPending = false; the original reads 1e6180 at
frame 12c and then enters 1e5d88, whose entry applies the setters (1e62b8) and whose exit is
1252f0(1, 1, 1e6130, 1e8850) after the autosave 10f158.

  win quote / VS result:  enter()  -> tick() once per 1126f0 visit, draw() from the .draw state
                          the exit leaves run.transition; at its midpoint call leave() (136288).
                          ArcadeVersusResult: the fighter object (ArcadeResultFighter, action
                          1fb from frame 64) is drawn by the fighter pipeline; pass its +c0.
  banner (kind 4):        on a kind-4 request begin(); tick(hidden) per visit; draw the banner
                          when .banner, VsCurtain::paint(.curtain) when >= 0; run
                          transitionMidpoint + old destructor + new entry on .swap; on
                          .finished call ArcadeRun::transitionFinished().
  name entry:             per 1c9928 visit drawArcadeNameCountdown(before tick), then
                          ArcadeNameEntry::tick, then drawArcadeNameEntry.
  unlock:                 UnlockSessionFlags = words 13430b0..cc (survival 1e3fd0; zero
                          otherwise); unlockPending() for the Game Over choice; enter()/tick()/
                          drawArcadeUnlockNotice with one ArcadeEdgePulse that lives for the
                          whole process (584ff8 / 584ffc are never reset); leave() at 1e6130.
