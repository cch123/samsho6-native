OPTION MODE and persistent system/save data (SLPS-25559)
=======================================================

Static reverse engineering of work/ss6/extracted/SLPS_255.59. No Probe run was
used; every statement is tagged
  OBSERVED  read directly from instructions/data at the cited address
  INFERRED  interpretation of observed code
  UNKNOWN   not resolved
ELF layout used: .text 0x100000..0x32cd70, .data 0x32ce00..0x5d3744 (file
backed, so 0x43d050.., 0x4c7510.., 0x5735c8.., 0x582b10.. have initial values in
the ELF), .rodata 0x5d3c00..0x67bc84, .bss from 0x67bd80.

Glossary
  CRC      cyclic redundancy check
  SJIS     Shift-JIS text encoding (all Japanese strings below)
  pad      118128(seat) -> pointer; +4 = pressed-edge word, +8 = auto-repeat word
  "live"   the block the game reads (g_GameOption at 0x43d058 etc.)
  "work"   the scene-local editable copy

Pad bits used by every option page (OBSERVED masks; button names INFERRED)
  edge & 0x20a  confirm        edge & 0x404  cancel
  0x10 up   0x20 down   0x40 left   0x80 right   (docs/input-processing.txt)
  edge & 0x100000 / 0x400000   page previous / next (INFERRED L1/R1; the legend
                               string is "ページ送り")
Sound requests are all 1e7b70(-1, id): id 0x20 cursor/value change, id 0x25
cancel/leave, id 0 confirm.

---------------------

Input word 1d2238(seat) (OBSERVED)
  edge&0x404 -> 0x400 (cancel)       edge&0x20a -> 0x100 (confirm)
  repeat up    -> 0x2000 | 0x01 | 0x10
  repeat down  -> 0x4000 | 0x02 | 0x20
  repeat left  -> 0x04 | 0x80
  repeat right -> 0x08 | 0x40
  edge&0x100000 -> 0x800             edge&0x400000 -> 0x1000

Per update, for seat in 0,1 (OBSERVED order; "sound n" = 1e7b70(-1,n))
  in = 0
  if inputReady() and state != 4 and slideState == 2: in = 1d2238(seat)
  if in & 0x100:
      if state == 0: state = 1; frame = 0
      elif state == 1: state = 2
      sound 0
  if state != 1:                               // browse (also runs in state 2)
      if in & 0x400:  1d0800() (leave); sound 0x25; frame = 0
      elif in & 0x2000: cursor = (cursor + 14) % 15
            if page == 0 and cursor == 12: cursor = 6
            if page != 0 and cursor == 6:  cursor = 14
            reload help; sound 0x20; frame = 0
      elif in & 0x4000: cursor = (cursor + 1) % 15
            if page == 0 and cursor == 7:  cursor = 13
            if page != 0 and cursor == 0:  cursor = 7
            reload help; sound 0x20; frame = 0
      elif in & 0x800 or in & 0x1000:
            page = (page + 1) % 2
            slideState = 0 (bit 0x800) or 1 (bit 0x1000)
            cursor = page == 0 ? 0 : 7; reload help
            1cf7c8() ([0x582b3c] = 0, legend fades in again)
            slideCounter = 0; sound 0x20; frame = 0
  if in & 0x8000: 1d0800(); sound 0x25         // bit never produced by 1d2238
  if state == 1:
      cursor 0..7, 10 (jump table 0x656db0 -> 1d02d4):
          if in & 0x400: live.bright = work.bright; work = live; state = 0;
                         sound 0x25; frame = 0          // discard edits
          elif in & 6:   1d0ad8() decrement; sound 0x20 // down or left
          elif in & 9:   1d0920() increment; sound 0x20 // up or right
      cursor 8, 9, 11, 12 (-> 1d0578):
          if in & 0x400: same discard
          elif in & 0x50: 1d0c98() +2;   sound 0x20     // up or right
          elif in & 0xa0: 1d0d80() -2;   sound 0x20     // down or left
      then (any cursor): if cursor == 13: 1d0840(page); sound 0
                         if cursor == 14: 1d0800();     sound 0
  if state == 2:                                        // commit
      work.bright = live.bright; live = work (0x98 bytes); state = 0;
      sound 0; frame = 0
after both seats: draw (below); frame++

  Value arithmetic (increment / decrement, OBSERVED)
    +4:  (v & 7) + 1          / ((v + 6) & 7) + 1
    +5:  (v + 1) % 3          / (v + 2) % 3
    +6:  v ^ 1                / v ^ 1
    +7:  (v + 1) % 15         / (v + 14) % 15
    +8:  (v % 5) + 1          / ((v + 3) % 5) + 1
    +9:  (v + 10) % 210       / (v + 200) % 210
    +0xc (live): v += 2, if v > 0x100: v = 0x38   /  v -= 2, if v < 0x38: v = 0x100
    +0x10, +0x13: (v + 1) % 3 / (v + 2) % 3
    +0x11, +0x12, +0x14, +0x15: (v + 2) % 202 / (v + 200) % 202
  DEFAULT SETTING 1d0840(page): live[0..3] = 0 always, then
    page 0: work.{+0xc = 0x100, +4 = 4, +5 = 0, +8 = 2, +9 = 100, +6 = 0, +7 = 0}
    page 1: work.{+0x10 = 0, +0x11 = [0x50d91c], +0x12 = [0x50d90c], +0x13 = 0,
                  +0x14 = [0x50d91c], +0x15 = [0x50d90c]}
    live = work (0x98 bytes); state = 0     (only the visible page is reset)
  Leave 1d0800: 1252f0(1, 0, 0x1d07e8, 0x1cfa10); state = 4. NOTE: leaving with
    cancel from browse does not undo anything: every commit already wrote live.

State machine

      +--------+ confirm  +------+ confirm +--------+
      | browse |--------->| edit |-------->| commit |--(same visit: live=work)--+
      | (0)    |<---------| (1)  |         | (2)    |                           |
      +--------+  cancel  +------+         +--------+                           |
        ^  | cancel / EXIT(14)   | cursor 13: reset page, -> browse             |
        |  v                     | cursor 14: leave                             |
        | leaving (4) -> option top                                             |
        +-----------------------------------------------------------------------+

  else: slideState = 1d1e20(slideCounter, 0, x0, x1, 0, slideState, page, 2,
        frame) with (x0,x1) = (0x280,-0x280) for slideState 0 and (-0x280,0x280)
        for 1; slideCounter++ (1d1e20 returns 2 once the counter reaches 15).

        rows at an eased x offset 1d21a0(t=counter/15, ...) + 0x44, and the
        middle band via 1cea80. INFERRED: 1d21a0 is a cubic Bezier
        u^3*p0 + 3u^2 t*p1 + 3u t^2*p2 + t^3*p3 (constants 1.0, 3.0 at
        0x657534/0x657538; four COP1 multiply-add opcodes are not decoded by
        analyze_elf.py). Validate with Probe before porting the slide.
  1d0e68(a)   banner rect 0x4c7678 at (16, 28, z=-350)
  1d1d00(cursor, a)  help text
